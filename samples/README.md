## 词表格式契约

**P1 的词表只有一个入口：导入 TSV。** v1.6 起工具内不再做 OCR / PDF 转换（见 `CLAUDE.md`
与 `PRODUCT_SPEC` 4.2 的 `〔v1.6 实施裁定〕`），扫描件的识别在工具之外完成——你给 TSV，工具负责读。
所以下面每一条都是硬要求。

读取逻辑在 `ui/vocab_view.py::load_tsv`，入库在 `core/database.py::import_word_list`。
**下列行为都实测过**（用真代码跑，不是从代码推的）。

### 必须满足

| # | 规则 | 违反了会怎样 |
|---|---|---|
| 1 | 每行**恰好三列**：`编号` `韩语` `中文` | 少于 3 列 → **该行被静默跳过**，只在提示里报「跳过 N 行（列数不足或没有韩文）」 |
| 2 | 列之间是**制表符 `\t`**，不是空格或逗号 | 整行变 1 列 → 全部跳过 → 报「这个文件里没有可用词条」 |
| 3 | **绝对不要表头行** | 表头会作为**一条真词条**入库（词=`韩语`、释义=`中文`），且它退化的编号与第 1 行相撞 |
| 4 | 编码 UTF-8（带不带 BOM 都行，按 `utf-8-sig` 读） | 其他编码 → `UnicodeDecodeError` → 报「读取词表失败」，**一条都不导入** |
| 5 | 第 2 列（韩语）不能为空 | 该行被静默跳过 |
| 6 | 第 1 列必须是整数 | 转不成整数会**静默**退化成"它在文件里的行号"，不报错 |
| 7 | 文件名会成为词表名（`Path(file_path).stem`） | 名字取好一点，它显示在单词仓里 |

### 实测的宽容之处（不用管）

| 输入 | 实际结果 |
|---|---|
| 第 2/3 列带首尾空格 | 解析层不 strip，但 `import_word_list` 入库时 `strip()` → **无影响** |
| 多出的第 4 列（如勾选列 `√`） | 前 3 列入库，第 4 列丢弃 |
| 空行夹在中间 | 跳过，无影响 |
| 行尾 `\n` 或 `\r\n` | 都行 |
| 编号补零（`001`）或不补（`1`） | 都行，按整数存 |

### 两条容易踩空的

- **被跳过的行不会让编号重排。** 若第 1 行格式不对被跳过，其余行仍带着自己的编号——
  表格里可能从 `2` 开始，而**这不会报错**。
- **字段内不能有制表符或换行符**，否则一条词条会被拆成两条。

### 示例

```
1	열이 내리다	退烧
2	느라고	因为
3	더라도	即使
```

编号建议补零到 3 位（`001` 起），与 `词表示例_中高级高频100.tsv` 一致：`f"{i:03d}\t{kr}\t{cn}"`。
（该样例实测为 UTF-8 无 BOM、LF 行尾、100 行、无表头——即本文档的标准形态。）

### 笔记归谁

笔记、三态（认识 / 模糊 / 不认识）、过词断点都按**「韩语」这一个字段**关联（D2；schema v2 起生效）。
~~旧写法是 `韩语 + "␟" + 中文` 做键~~——那是 v1 的做法，v2 迁移时已废弃。

后果有两个，都符合预期：**同一个韩语词出现在多份词表里会共享同一份笔记**；
而同一个韩语词若配了不同释义，也仍是同一条笔记。

### 重新导入

以**同一文件路径**再导一次 = 重新导入：`word_lists` 行按 `source_path` 复用，`words` 整体重建，
而 `word_notes` / `word_list_progress` **一个字段都不碰**。这就是"重新导入不丢笔记"的具体含义。

### 删除词表

工具条上的「删除词表」删的是**当前选中的那一份**（「全部词表」不是实体，那里按钮是禁用的）。
删除有一条硬规则：**只删第一层。**

| | 删掉 | 保留 |
|---|---|---|
| 词表行 `word_lists` | ✓ | |
| 词条 `words` | ✓ | |
| 断点与轮次 `word_list_progress` | ✓ | |
| 笔记 / 三态 / 重点 `word_notes` | | ✓ |
| 状态流水 `word_state_log` | | ✓ |

所以 **删掉再导入同一份 TSV，笔记、三态与重点标记会跟着回来**（断点不回来，会从第 1 个词重新开始）。

为什么不连笔记一起删：笔记按**「韩语」这一个字段**关联（见上「笔记归谁」），同一个词若还在
别的词表里，那份笔记是共用的——按词表删会把别的词表的数据一起带走。

**如果你的 TSV 生成错了想重来**：改好文件后直接再导入一次就够了，不必先删（同一路径即重新导入，
笔记本来就保留）。删除只用于"这份词表我不想要了"。
